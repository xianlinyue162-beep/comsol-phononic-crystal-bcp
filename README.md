# COMSOL Phononic Crystal Notes

This repository is a lightweight public placeholder for selected notes around COMSOL-based phononic-crystal modeling workflows.

Detailed private research formulas, coefficients, stage reports, solver outputs, COMSOL models, and internal fitting data are not included here.

## Public Scope

This public page may be used later for:

- high-level project updates,
- non-sensitive workflow notes,
- general COMSOL modeling lessons,
- links to public writeups that do not expose private formulas or raw research data.

## Not Included

The following remain private:

- private formulas and parameter choices,
- target band-shape definitions,
- detailed route/coupling terms,
- COMSOL `.mph` models,
- generated solver outputs,
- internal metrics and stage reports,
- unreleased scripts and fitting data.
